## Пункт 1: Структура даних уроків та реєстр (Data Model & Schema)

### Мета
Створити структуру даних у файлі `js/data/lessons.js`, яка зберігає контент уроків у вигляді конфігураційних об'єктів. Кожен урок складається з масиву універсальних блоків (`sections`) та підтримує переклад будь-якою мовою користувача (`translations: { uk: "...", en: "..." }`).

### Файли для створення/зміни
- `js/data/lessons.js` (новий файл)

### Вимоги до реалізації
1. Створити глобальний об'єкт `window.LS_LESSONS = { ... }`.
2. Кожен урок має унікальний ідентифікатор (наприклад, `"communication-basics-1"`).
3. Обов'язкові метадані уроку:
   - `id`: рядок (унікальний ключ уроку)
   - `unitId`: рядок (ідентифікатор теми/розділу, напр. `"communication-basics"`)
   - `unitTitle`: об'єкт перекладів `{ uk: "Основи спілкування", en: "Communication basics" }`
   - `lessonNum`: число (номер уроку в розділі)
   - `type`: рядок (`"dialogue"` | `"reading"` | `"grammar"` | `"checkpoint"`)
   - `title`: об'єкт перекладів `{ uk: "Знайомство", en: "Introductions" }`
   - `subtitle`: об'єкт перекладів
   - `duration`: рядок (напр. `"15 хв"`)
   - `xpReward`: число (напр. `50`)
   - `nextLessonId`: рядок або `null`
   - `prevLessonId`: рядок або `null`
4. Підтримувані типи блоків у `sections`:
   - **`dialogue`**:
     - `image`: шлях до зображення сцени
     - `lines`: масив реплік `[{ speaker: "Anna", it: "Buongiorno!", translations: { uk: "Доброго дня!", en: "Good day!" } }]`
   - **`story_text`** (для читання текстів/історій):
     - `image`: шлях до зображення (необов'язково)
     - `paragraphs`: масив абзаців `[{ it: "...", translations: { uk: "...", en: "..." } }]`
     - `vocabHints`: словникові підказки для слів у тексті
   - **`vocab`**:
     - `title`: об'єкт перекладів
     - `items`: масив слів `[{ it: "piacere", transcription: "[п’я-че-ре]", translations: { uk: "приємно", en: "nice to meet you" } }]`
     - `notes`: масив пояснень/нотаток
   - **`grammar_rule`**:
     - `title`: об'єкт перекладів
     - `explanation`: об'єкт перекладів
     - `table`: таблиця відмінювань/правил (колонки та рядки)
   - **`takeaways`**:
     - `items`: список ключових тез уроку
   - **`culture_note`**:
     - `title`: об'єкт перекладів
     - `text`: об'єкт перекладів
   - **`quiz`**:
     - `tasks`: масив завдань різних типів:
       - `choice`: питання з варіантами відповідей
       - `true_false`: твердження (так/ні)
       - `fill_blank`: речення з пропущеним словом
5. Перенести повний контент наявного Уроку 1 (`pages/communication-basics/communication-basics-lesson-1.html`) у `communication-basics-1` у форматі `LS_LESSONS`.
6. Додати шаблонні приклади для уроку читання (`"reading"`) та уроку граматики (`"grammar"`).

## Пункт 2: Блочний движок рендерингу (Lesson Engine)

### Мета
Створити скрипт `js/lesson-engine.js`, який отримує об'єкт уроку з `LS_LESSONS`, визначає поточну мову інтерфейсу користувача та генерує відповідну HTML-розмітку для кожного блоку.

### Файли для створення/зміни
- `js/lesson-engine.js` (новий файл)

### Вимоги до реалізації
1. **Визначення мови:**
   - Інтегрувати з існуючим `getSourceLanguage()` з `js/app.js` (значення `'uk'` або `'en'`).
   - Створити хелпер `t(translatableObject, fallback = '')`, який повертає текст поточною мовою користувача або повертається до `'uk'`.
2. **Карта рендерерів блоків (`BLOCK_RENDERERS`):**
   - `renderDialogueBlock(section, lang)`: рендерить сцену, зображення та діалогові бульбашки реплік.
   - `renderStoryTextBlock(section, lang)`: рендерить текст для читання, абзаци та інтерактивні клікабельні підказки до слів.
   - `renderVocabBlock(section, lang)`: рендерить словникову таблицю з італійським словом, перекладом, вимовою та примітками.
   - `renderGrammarBlock(section, lang)`: рендерить картку правила та таблицю відмінювання дієслів/артиклів.
   - `renderCultureBlock(section, lang)`: рендерить культурну нотатку.
   - `renderTakeawaysBlock(section, lang)`: рендерить список підсумків уроку.
   - `renderQuizBlock(section, lang)`: рендерить інтерактивні тести (множинний вибір, правда/ні, вставка слів) з кнопкою перевірки.
3. **Логіка тестування та нагороди XP:**
   - Збирати відповіді користувача при натисканні «Перевірити завдання».
   - Підсвічувати правильні/неправильні поля.
   - Показувати результат у відсотках.
   - При успішному проходженні (>70%): викликати `awardXP(lesson.xpReward)` з `app.js` та позначати урок у `localStorage` як пройдений (`ls_completed_lessons`).
4. **Підтримка живої зміни мови:**
   - Підписатися на подію зміни мови або експортувати функцію `rerenderCurrentLesson()`, щоб при виборі нової мови в профілі сторінка миттєво оновлювала всі переклади без перезавантаження.

## Пункт 3: Універсальний шаблон сторінки уроку (`pages/lesson.html`)

### Мета
Створити єдину точку входу для всіх уроків — сторінку `pages/lesson.html`. Сторінка завантажує спільні компоненти (`navbar`, `footer`) і відображає обраний урок за параметром URL (наприклад, `pages/lesson.html?id=communication-basics-1`).

### Файли для створення/зміни
- `pages/lesson.html` (новий файл)
- `css/lesson.css` (використовувати існуючі стилі розмітки уроку)

### Вимоги до реалізації
1. **Підключення ресурсів:**
   - `<div data-component="navbar"></div>`
   - `css/main.css`, `css/lesson.css`
   - `js/icons.js`, `js/components.js`, `js/app.js`
   - `js/data/lessons.js`
   - `js/lesson-engine.js`
   - `<div data-component="footer"></div>`
2. **Каркас сторінки (`.lesson-layout-wrapper`):**
   - **Бокове меню уроків (`aside#sidebar`):**
     - Відображає назву розділу та список усіх уроків розділу.
     - Уроки автоматично маркуються: `Активний`, `Пройдено` (з галочкою), `Заблоковано` на основі `localStorage`.
     - Кнопка відкриття/закриття меню на мобільних пристроях.
   - **Основна зона контенту (`main.lesson-content`):**
     - Хедер уроку: хлібні крихти, тег типу уроку (`Діалог`, `Текст`, `Граматика`), заголовок, опис.
     - Контейнер `#lessonBody`: сюди `lesson-engine.js` монтує згенеровані блоки.
     - Футер навігації: кнопки «← Попередній урок» та «Наступний урок →».
3. **Маршрутизація (URL resolution):**
   - Читати ідентифікатор уроку з `new URLSearchParams(window.location.search).get('id')` або хешу `window.location.hash.slice(1)`.
   - Якщо параметр відсутній або урок не знайдено — показувати дружню сторінку вибору уроку або перенаправляти на перший урок за замовчуванням.

## Пункт 4: Міграція існуючих посилань та сумісність

### Мета
Оновити навігацію на всьому сайті, щоб посилання на уроки вели на динамічний шаблон `pages/lesson.html?id=...`, а старі прямі URL коректно перенаправлялися.

### Файли для створення/зміни
- `pages/path.html`
- `index.html`
- `components/navbar.html`
- `components/mobile-nav.html`
- `pages/communication-basics/communication-basics-lesson-1.html` (додати автоматичний редирект)

### Вимоги до реалізації
1. Замінити посилання `pages/communication-basics/communication-basics-lesson-1.html` на `pages/lesson.html?id=communication-basics-1` у меню та навігаційних кнопках.
2. У `pages/communication-basics/communication-basics-lesson-1.html` розмістити скрипт безшовного редиректу:
   ```html
   <meta http-equiv="refresh" content="0; url=../lesson.html?id=communication-basics-1">
   <script>window.location.replace('../lesson.html?id=communication-basics-1');</script>
   ```
3. Перевірити, що підсвічування активного пункту меню в `js/components.js` коректно розпізнає `lesson.html`.

## Пункт 5: Масштабування на нові мови навчання та цільові мови

### Мета
Забезпечити архітектурну готовність платформи до додавання:
1. Нових мов перекладу (наприклад, польської `pl`, німецької `de`).
2. Нових мов для вивчення (наприклад, курс іспанської чи французької замість італійської).

### Інструкція для додавання мови інтерфейсу/перекладу:
1. У `js/data/lessons.js` додати новий ключ у поле `translations` для потрібних уроків:
   ```javascript
   translations: {
     uk: "Доброго дня!",
     en: "Good day!",
     pl: "Dzień dobry!"
   }
   ```
2. У модальне вікно профілю (`components/profile-modal.html`) додати новий `<option value="pl">Polski</option>`.
3. Готово — рушій `lesson-engine.js` автоматично відображатиме нову мову, якщо користувач обере її в налаштуваннях.

### Інструкція для додавання нового курсу (нова цільова мова):
1. Створити окремий реєстр курсу, наприклад `js/data/lessons-es.js` (іспанська) або об'єднати курси за структурою:
   ```javascript
   window.LS_COURSES = {
     italian: { title: "Італійська мова", lessons: { ... } },
     spanish: { title: "Іспанська мова", lessons: { ... } }
   };
   ```
2. Зберігати обраний курс у `localStorage.getItem('ls_target_course') || 'italian'`.
3. У `lesson.html` передавати параметр курсу: `pages/lesson.html?course=spanish&id=basics-1`.

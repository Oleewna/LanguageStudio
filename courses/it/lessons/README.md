# Italian lesson data

The first three lessons from `lessons/communication-basics.md` are integrated into the Italian course:

- `communication-basics-1` — Hello, how are you?
- `communication-basics-1-greetings` — Polite greetings
- `communication-basics-1-practice` — What is your name?

The remaining source lessons are not yet integrated. See the [human-readable exports and re-adding instructions](../../../lessons/README.md).

Additional practice questions in `../exercises.json` use `pathId` and `lessonId` to appear under the matching lesson on the exercises page.

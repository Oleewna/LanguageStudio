## 1. Overview & Purpose

The **Learning Path Page** is the full interactive curriculum map of a course. It renders the pedagogical journey from foundational basics to situational fluency. It organizes content hierarchically into **Categories**, **Units**, and **Lessons**, showing visual connection splines, real-time completion checkmarks, and locked premium milestones.

## 3. Curriculum Hierarchy & Course Data Model

Content is fetched from `courses/{courseId}/course.json` or `/api/courses/{courseId}`:
- **Categories**: High-level thematic sections (e.g. `communication-basics`, `travel-situations`, `italian-reading`).
- **Units**: Structural chapters within a category (e.g. Unit 1: "First Meeting & Polite Phrases").
- **Lessons**: Individual executable study units (e.g. `communication-basics-1`, `communication-basics-2`).

## 4. Lesson Node States & Gating Logic

`js/path.js` and `js/path-progress.js` compute the visual state of every node in real time:

| State | CSS Class | Visual Cue | Condition | Action |
|---|---|---|---|---|
| **Completed** | `.node-completed` | Green border, checkmark icon, best score percentage | Lesson ID present in user's completed lessons set. | Re-playable anytime for review or score improvement. |
| **Active** | `.node-active` | Brand highlight, pulsing aura, "Start" badge | First uncompleted lesson in the sequence whose prerequisites are met. | Clicking navigates to `pages/lesson.html?course=it&lesson={id}`. |
| **Free Locked** | `.node-locked` | Dimmed opacity, lock icon | Previous prerequisite lesson has not yet been completed. | Clicking displays a tooltip indicating prerequisite lesson required. |
| **Premium Locked** | `.node-premium` | Gold/purple border, crown/padlock badge | Lesson is part of a premium paid path and user lacks active `Entitlement`. | Clicking opens prompt linking to `pages/pricing.html` or `pages/checkout.html`. |

## 5. Post-Checkout & Testing Unlocking Flows

### 5.1 Post-Checkout Flow (`?unlocked=true`)
When a user completes payment on `pricing.html` or `checkout.html`, they are redirected to:
```
/pages/path.html?unlocked=true
```
- `path.js` detects the `unlocked=true` query parameter.
- Re-fetches the user's active entitlements via `/api/payments/entitlements`.
- Displays a celebratory banner (*"Your course path is now unlocked!"*).
- Removes padlock badges from newly purchased units and enables the nodes immediately.

### 5.2 Developer Testing Unlock (`#btnDevUnlock`)
In development and testing environments, learners and developers can bypass the checkout workflow:
- Clicking **"Unlock all paths for testing"** invokes `unlockForTesting()`.
- Dispatches a `POST /api/payments/dev-unlock` request without requiring credentials.
- Backend issues a wildcard entitlement (`selectedPaths: ['*']`) for the session.
- Path nodes re-render immediately with all restrictions and locks removed.

## 6. SVG Connection Splines (`js/path-connectors.js`)

To create an intuitive visual map:
- `path-connectors.js` computes the DOM coordinates (`getBoundingClientRect`) of adjacent lesson circles.
- Injects SVG `<path>` elements with smooth cubic Bézier curves (`M x1 y1 C ... x2 y2`).
- Dynamically recalculates connector geometry on window resize or when accordions expand/collapse.

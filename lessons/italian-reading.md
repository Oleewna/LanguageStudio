## Rule 01 — Hard C: ca, co, cu / Тверда C: ca, co, cu

<a id="italian-reading-rule-01"></a>

**rule_id:** `italian-reading-rule-01`
**lesson_id:** `italian-reading-2`
**Duration / Тривалість:** 5 хв / 5 min
**Experience reward:** 35

**Subtitle / Підзаголовок**

- **Українською:** Читай ca, co та cu
- **English:** Read ca, co, and cu

**Description / Опис**

- **Українською:** Почуйте твердий звук C у складах ca, co, cu та знайдіть його у знайомих словах.
- **English:** Hear the hard C sound in ca, co, cu and find it in familiar words.
### Rule / Правило

- **Українською:** ca, co, cu = [к], як у «котик», «книга», «кухня».
- **English:** ca, co, cu = [k], as in "kotyk", "knyha", "kuchnia".

## Rule 02 — C before E and I: soft ce/ci, hard che/chi / C перед E та I: м’які ce/ci, тверді che/chi

**rule_id:** `italian-reading-rule-02`

**Experience reward:** 35

**Subtitle / Підзаголовок**

- **Українською:** Почуй різницю між C та CH
- **English:** Hear the difference between C and CH

**Description / Опис**

- **Українською:** Розрізняйте м’яку C у ce/ci та тверду C у che/chi.
